# 코코드론 홍보 사이트 시안 3종

(주)코코드론의 제품·대회 홍보 사이트 디자인 시안입니다. 같은 내용을 세 가지 컨셉으로 구현했습니다.

| 시안 | 폴더 | 컨셉 |
|---|---|---|
| A | `demo-a/` | 브랜드 스토리형. 휠 한 번에 한 장면씩 넘어가는 풀스크린 연출 |
| B | `demo-b/` | 기업 사이트형. 부드러운 스크롤과 구간별 모션 |
| C | `demo-c/` | 스토어·이벤트형. 배너, 고정 탭, 카드 구성 |

공통 기능: 한국어·영어·일본어·스페인어 전환, 대회 소개와 홍보 영상, 제품 목록(클릭 시 링크 이동), 공지사항, 로그인 없는 참가 신청, 스마트스토어 바로가기.

- 빌드 과정이 없는 정적 사이트입니다. 폴더를 그대로 웹 서버에 올리면 동작합니다.
- 문구와 콘텐츠는 `shared/coco-data.js`, 다국어·신청 처리는 `shared/coco-core.js` 에 있습니다.
- 이미지와 영상은 Higgsfield로 생성한 시안용이고, 대회명·일정·장소는 예시입니다.
- 참가 신청 내용은 시안 단계라 방문자의 브라우저에만 저장됩니다.
